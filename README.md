# Thesis Repository

This repository contains the experimental materials, data, and analysis scripts for my master's thesis "Investigating Heterogeneity of
Common Ground".

## Repository Structure

- `.github/workflows/` – GitHub Actions workflows.
- `data/` – Experimental data, R scripts for data analysis, plots, and related outputs.
- `experiments/` – Magpie code for running and replicating the experiments, including pilot, main, and dummy versions.
- `items/` – All experimental items and texts used in the experiments.


The full experiment can be viewed and tested here: https://cogsciprag.github.io/A1-indicom/experiments/A1-Indicom-dummy/
